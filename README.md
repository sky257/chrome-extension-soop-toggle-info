# SOOP 플레이어 단축키

| 단축키 | 동작 |
|-|-|
| `Ctrl + I` | 하단 플레이바(진행바 + 컨트롤), 상단 정보(프로필, 제목, 조회수), 우측 상단 버튼(채팅 말풍선, 방송리스트 등) 숨기기 / 보이기 |
| `>` (Shift + .) | 재생 속도 올리기 |
| `<` (Shift + ,) | 재생 속도 내리기 |
| `Ctrl + ← / →` | 1분 뒤로 / 앞으로 |
| `Shift + ← / →` | 5분 뒤로 / 앞으로 |

- 모든 단축키는 일반 화면, 스크린모드, 전체화면 모두에서 동작합니다. (상단 정보는 SOOP이 스크린모드/전체화면에서만 표시합니다.) `Ctrl + I`로 숨긴 상태는 전체화면에 들어가거나 나가도 그대로 유지되고, 다시 누르면 보입니다.
- 재생 속도는 유튜브와 같은 단계(0.25 ~ 2배)로 바뀌고 화면 상단에 현재 속도가 잠깐 표시됩니다. 라이브 방송에서는 동작하지 않습니다.
- Ctrl/Shift + 화살표는 SOOP 기본 10초 이동 대신 1분/5분 이동하고, 화면에 이동량이 잠깐 표시됩니다. 영상 처음/끝을 넘어가지 않고, 라이브 방송에서는 동작하지 않습니다.
- 채팅 입력창 등에 입력 중일 때는 단축키가 동작하지 않습니다.

## 설치
1. `chrome://extensions` 열기
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 폴더 선택
